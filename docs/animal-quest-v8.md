# 黑貓的委託（v8）

## 怎麼玩

1. 按左上「去半山腰，和黑貓聊聊」，沿虛線步行。靠近動物按 E／手機「互動」。
2. 黑貓會介紹四維堂旁的臺灣藍鵲。新目標自動帶路，也能隨時點任務提示重新帶路。
3. 藍鵲的玻璃珠掉在人行道。觀察人類視線，等對方轉身再靠近拾取；警覺／追逐中不能互動。花叢裡按住 C 可以躲藏。
4. 把收藏交還藍鵲，再回報黑貓。取得「藍鵲偵察」，打開地圖看到橘色人類標記。
5. 地圖與對話期間遊戲暫停。偵察顯示開啟地圖時的人類位置，不預測未來路線。

## 產品結構

任務進度是一份共用記事本。`quest.mjs` 決定目前階段、能對誰互動，以及下一個目的地；畫面與地圖使用同一份進度。`save.mjs` 把有效進度寫進瀏覽器，本機儲存像留在這台電腦的小筆記。

選用固定五步任務，優點是目標明確、容易驗證完整循環；替代方案為分支任務，但對話、存檔與路線組合會變多，本輪不擴充。保留現有 ES module／Canvas 與原生 dialog，不新增套件、登入或服務費。

## 存檔與失敗

- 自動記錄任務階段、已發現地點、已完成搞怪；不記錄即時座標，重開從校門安全出發。
- 被抓、按 R 回基地都保留上述進度與已取得收藏。
- 同一瀏覽器、同一網址來源才能讀取；無雲端同步。清除網站資料會失去進度。
- 讀取資料時檢查版本、階段及地點 ID 白名單；損壞／不相容資料保留原樣，不覆寫，畫面提示無法存檔。
- 任務資料不作為 HTML 執行。不含個人資料、外部網路服務或多人排行榜；本機修改存檔並非反作弊防護範圍。

## 限制

這是第一條完整線性委託。NPC 為靜態模型生成圖像，尚無移動動畫、配音、分支選項、動物跟隨、室內、雲端存檔或任務重置介面。校園保留既有藝術化配置；不是導航工具。未宣稱任天堂認證或主機品質完成。
