# 往 Sneaky Sasquatch 的質感前進 — 規劃

最後更新：2026-10-20

> **方向再調整（2026-10-20 下午）**：不再照實際校園建模。改做像 Sneaky Sasquatch 的純玩法遊戲，一塊一塊集中做小而密的區域。第一塊「溪邊篇：醉夢溪野餐草地」已取代正式遊戲（舊全校版在 classic.html）。下一塊候選：宿舍區（外送、曬衣場、夜間潛行）、自助餐與商圈（排隊、餐盤、便利商店）。下方的挖地道、動物圖鑑、捲球滾下坡會放進這些新區域裡做。

參考：使用者提供的 32 張 Sneaky Sasquatch（RAC7）截圖。目標是**畫面質感、鏡頭、手感與玩法結構**達到同等級；角色、美術、介面圖示全部原創，主角仍是機械穿山甲，舞台仍是政大。不描摹、不仿製其角色與圖示。

## 一、差距盤點（截圖 vs. 現在 v14）

| 面向 | 參考截圖 | 現在的遊戲 | 差距 |
|---|---|---|---|
| 視角 | 統一正俯視（top-down 3/4）：地面平鋪，物件只露正面與頂面 | 地面俯視，但建築是斜 45° 等角圖，透視混在一起 | **最大** |
| 美術語言 | 純平面向量、無描邊、少量色塊陰影、圓潤幾何、色盤有限 | AI 生成建築（細節多、光影寫實）＋平面角色，兩種畫風並存 | 大 |
| 鏡頭 | 很近，角色約佔畫面高 1/8；手機橫向 | 角色較小，大片空草地；手機直向 | 大 |
| 場景密度 | 每個畫面都有小物：木柴、冷藏箱、香菇、石頭、野餐墊、營火、鵝 | 草地、樹、樹叢、建築，畫面空 | 大 |
| 介面 | 只剩左下背包＋右下情境鈕，必要時才出現計時/體力 | 任務鈕、地圖圓、說明鈕、地點、足跡、搖桿等多個常駐元件 | 中 |
| 角色 | 大頭、圓身、動作誇張（吃、釣魚、滑雪各有姿勢） | 單一走路圖，4 方向 | 中 |
| 互動特寫 | 方向盤、電腦、吊車拉桿：手入鏡 | v14 已有三個搞怪特寫 | 小（已起步） |
| 核心循環 | 偷吃→體力→賣東西賺錢→買道具→解鎖新區域 | 任務鏈＋三個搞怪，沒有可累積的東西 | 大 |
| 變裝/室內 | 穿上衣服進城：銀行、超市、餐廳、上班 | 建築不能進入 | 大 |
| 小遊戲 | 高爾夫、卡丁車、釣魚、划船、滑雪、衝浪、潛水… | 無 | 大（但不必全做） |
| 時間與天氣 | 夏、雪、洞穴提燈、夜晚車燈 | 永遠白天 | 中 |

結論：**先決勝負的是視角與美術統一**。玩法再多，畫面透視不一致就不會像。所以第一階段只做「看起來對」。

## 二、美術方向（2026-10-20 更新為實際採用的做法）

> 最早的「無描邊正俯視、大頭圓身」樣張被使用者否決（造型醜、與原遊戲不一致），以下為現行規則。

- **畫風沿用原本穿山甲遊戲**：地面是俯視地圖（草地紋理、原本的車道灰／石磚／路緣色）；建築與物件是 3/4 立體插畫，看得到正面、東側面、頂面，細深色描線，頂面最亮、側面最暗，窗戶深青色玻璃加反光（同 gatehouse-v12、gate-1）。
- **角色**沿用原本切面風格的穿山甲與戴草帽路人圖，以換色做出警衛、慢跑者、學生等。
- **位置與建築配置照 wenzhotw/nccu100** 的公尺座標，一塊一塊做（`src/regions/*.mjs` 資料、`src/art/region.mjs` 繪製）；每個資料點註明來源檔。
- **素材**：原本已有的插畫直接沿用；沒有的用程式依同一套畫法繪製，顏色只從 `src/art/palette.mjs` 取。

## 三、分階段路線

每一階段都是可上線的版本，走完一階段就推 GitHub Pages。

### 階段 1 — 看起來對（v15）
1. 寫 Art Bible 色盤常數與 SVG 繪製工具（建築、樹、樹叢、小物件的生成函式）。
2. 依 nccu100 一塊一塊做。已完成區域一「正門到噴水池」（sample.html）；下一塊：噴水池到四維堂。
3. 鋪小物件：長椅、垃圾桶、腳踏車架、路燈、落葉、香菇、松鼠/鴿子（會被嚇飛）。
4. 鏡頭拉近（桌機約 2.4、手機約 1.8 倍），角色放大；手機改成**橫向優先**，直向時顯示「轉橫向更好玩」。
5. ~~人物改畫成大頭圓身~~ → 沿用原本切面風格角色，換色做出至少 3 種路人。
驗收：同一段路的新舊截圖對比；桌機與手機橫向各兩輪自評。

### 階段 2 — 介面減法（v15.1）
- 常駐只留：左下**背包鈕**（打開後才看到任務、地圖、足跡、說明）、右下**情境鈕**（依靠近的東西變成「撿起／對話／搞怪／躲藏」）。
- 地點名稱只在第一次走進該區時淡入 2 秒。
- 危險提示改用畫面邊緣微紅暈＋人物頭上「!」，取消文字條。

### 階段 3 — 穿山甲限定玩法（v16～v17，2026-10-20 使用者決定先做）

共同原則：**只用現有兩顆按鈕**（互動、躲藏），依位置自動變成不同動作；單手可玩；每種玩法都產出東西回到背包與動物朋友，而不是各玩各的。

#### 3a 吃螞蟻覓食（先做：其他玩法的體力來源）— 2026-10-20 已上線 v16
- **體力**：畫面角落一個圓餅。走路緩慢消耗；挖洞、滾球消耗較多；見底時走路變慢、不能挖洞。
- **蟻窩**：草地、樹根旁、花台邊緣散布蟻丘（每區 3～5 個，吃完過一段時間重生）。靠近時「互動」變成「吃螞蟻」。
- **小遊戲**：特寫畫面（沿用搞怪特寫的對話框），長舌伸進蟻道，螞蟻沿線爬出來時點擊；連續點中加成，點到兵蟻會被咬、扣一點。15～20 秒一局。
- **風險**：吃的時候算是「蹲著不動」，路人看過來仍會被發現；所以要挑睡覺或滑手機的路人旁邊吃，正好用上 v14 的習慣泡泡。
- 驗收：體力歸零、吃滿、被打斷三種狀態都有測試；手機一局內點擊判定不誤觸。

#### 3b 挖地道
- **洞口**：鬆土標記（花叢、樹下、草坪邊）。站在上面「按住躲藏」1 秒開挖，鑽進地底。
- **地底移動**：畫面變暗、只看得到附近的洞口與地底的東西，路人看不到你；拖曳移動，靠近另一個洞口放手就冒出來。地底移動消耗體力，太久會被逼出地面。
- **用途**：
  - 捷徑與逃跑：被追時鑽進洞裡，追的人會失去目標。
  - 挖寶：地底有埋藏物，例如瓶蓋、舊校徽、百年校慶時光膠囊的碎片，可以放進背包。
  - 新路線：有些區域只能從地道進去，例如圍牆後面、花圃中間。
- **規則**：不能挖穿建築與道路，地道只連同一區內的洞口；洞口位置寫在區域資料檔。
- 驗收：被追 → 鑽洞 → 追逐解除；地底與地面座標一致；存檔記住已挖開的洞口。

#### 3c 校園動物圖鑑
- **記錄方式**：慢慢靠近動物，不跑、不被看見；在牠的「安心範圍」內停留 2 秒，就寫進圖鑑。跑太快或太近，動物會飛走或逃跑（沿用目前鴿子被嚇飛的反應）。
- **第一批動物**：鴿子、黑貓、臺灣藍鵲、松鼠、醉夢溪的白鷺鷥、校園狗、夜間的蛙類。每種有自己的習性與出沒時間，部分需要夜晚或雨天。
- **圖鑑頁**：放在背包裡，每種動物一張卡：插畫、出沒地點、一句動物的話。集滿一區可以向黑貓或藍鵲換獎勵，例如看得到螞蟻的眼睛、挖得比較快的爪子。
- 驗收：嚇跑與成功記錄的判定有測試；圖鑑進度存檔且向下相容。

#### 3d 捲球滾下坡（需要有坡道的區域，排在最後）
- 在坡道上一邊移動一邊「按住躲藏」，就會捲成球往下滾，速度隨坡度增加；拖曳只能微調方向，放開躲藏就停下。
- **場地**：環山道、山上校區往下的步道、指南路坡段（要等這些區域做出來）。
- **挑戰**：計時賽，沿路收集落葉或松果；撞到路人會嚇到對方並觸發警戒，撞到障礙物會彈開、扣體力。
- 驗收：坡度資料寫在區域檔；平地按躲藏仍是原本的蜷縮躲藏，不會誤觸滾動。

### 階段 4 — 背包與動物朋友（v18，原「能累積的核心循環」）
- **偷吃人類食物**（改為次要）：體力主要來自吃螞蟻；自助餐餐盤、醉夢湖野餐只是偶爾的大補，被抓到風險較高。
- **背包**：挖到的、撿到的東西（瓶蓋、舊校徽、遺失的學生證…）和動物圖鑑都放這裡，可交給動物朋友換獎勵。
- **動物商店**：黑貓收集閃亮東西、藍鵲情報、松鼠換堅果；用收藏解鎖新區域或新道具（例如會發光的眼睛＝夜間視野）。

### 階段 5 — 變裝與室內（v19）
- 穿山甲穿上政大帽T＋背書包＝「學生偽裝」，路人不會立刻起疑，但被近距離盯太久會穿幫。
- 先開 2 個室內：**中正圖書館**（安靜，跑步會被噓）、**自助餐**（偷餐盤、排隊）。
- 室內用同一套正俯視規則，門口切換場景。

### 階段 6 — 小遊戲（v20，挑 2 個）
- 候選：醉夢溪抓魚（時機點擊）、河堤騎 YouBike 計時賽、選課搶課（節奏點擊）、四維堂前的迷你高爾夫。
- 原則：每個 1–2 分鐘、單手可玩、獎勵回到背包/商店循環。

### 階段 7 — 時間與天氣（v21）
- 白天／黃昏／夜晚：夜晚只看得到手電筒光圈（警衛巡邏），呼應截圖的洞穴提燈；夜晚才出現的動物進圖鑑。
- 木柵雨天：路人撐傘、視線變短、步道變滑。

## 五、已決定（2026-10-20 使用者確認）

1. 美術管線：**程式產生 SVG 向量**，共用色盤常數。
2. 手機：**橫向優先**，直向時提示轉向。
3. ~~階段 1、2 之後先做偷吃與背包循環~~ → 2026-10-20 改為：**先做穿山甲限定玩法**（吃螞蟻、挖地道、動物圖鑑、捲球滾下坡），再做背包與動物朋友；偷吃人類食物降為次要。
4. 地圖與建築：**照 wenzhotw/nccu100 一塊一塊做**，畫風沿用原本遊戲。
5. 手機操作：**按住畫面任何地方就是搖桿**（v15 已上線），玩法只用互動、躲藏兩顆按鈕。
