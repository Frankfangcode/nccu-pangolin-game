# v13 小段冒險打磨

授權：先讓正門、林蔭步道、黑貓、藍鵲這段值得反覆玩。沿用平面卡通、現有任務與存檔；不加入另一款小遊戲或外部服務。

## 體驗
黑貓下山散步，在校門內等待。沿路找藍鵲、等待巡邏轉身取回收藏、帶回樹上，再找黑貓。拿著的收藏與樹上的收藏是任務狀態的視覺結果，不另存一份背包資料。場景反應在對話關閉後開始，不妨礙移動。

## 實作與驗收
1. TDD：先驗證首個朋友不需橫跨校園，紅→移動黑貓至入口步道→綠。
2. TDD：拾取／交付／交友只發一次事件，危險狀態不發事件，紅→互動事件→綠。
3. TDD：攜帶狀態只在取回與交付之間存在，安全且靠近才迎接，紅→場景狀態推導→綠。
4. 畫面：入口樹蔭、動物微動、收藏轉移、對話時收起多餘指示；減少動態偏好不位移。
5. QA：真實鍵盤完整任務，375×812搖桿、對話、暫停與重載。兩輪1280×800與375×812圖片自評。檢查圖層／主次／留白／字級／色彩／對齊／狀態／動效。
6. 全套Node測試、語法、人工差異審查、偵測；提交main，重新全測，推送既有GitHub Pages，驗證原網址。

## 邊界
建築尺度與真實校園測繪仍為既有限制。沿用素材，不宣稱完成所有校舍美術重繪。沒有新增帳號、付款或網路資料上傳；進度留在瀏覽器。AI從新玩家、手機操作、遊戲回饋、存檔一致性角度檢查，不冒稱真人專家。
