# 穿山甲出沒 · 政大校園小冒險

原創 2D 瀏覽器遊戲。透過機械穿山甲探索政大校園，結識黑貓與臺灣藍鵲，避開人類、找回收藏，解鎖偵察能力。

目前版本 **v11.1**：精簡遊戲介面、圓形局部小地圖、手機類比搖桿。校園配置為藝術化示意，不供實地導航。

## 本機遊玩

需要 Python 3，無須安裝套件。在專案資料夾執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8765/ 。亦可執行 `python3 play.py` 自動開啟隨機本機連接埠。瀏覽器存檔依網址來源區分；要接續同一份進度，請固定使用同一個主機名稱與連接埠。

## 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD／方向鍵 | 左下搖桿，輕推慢走、放手停下 |
| 互動 | E／空白鍵 | 右下「互動」 |
| 躲藏 | 按住 C／Shift | 按住「躲藏」，可與搖桿雙指操作 |
| 回基地 | R | 全圖內選回基地路線 |
| 全圖 | 點右上圓形小地圖 | 同左 |
| 說明 | 右上 ? | 同左 |

點左上任務開始帶路。到半山腰與黑貓對話，再到四維堂樹下找藍鵲。樹叢裡蜷縮才能隱藏；被抓後回基地，任務進度保留。

## 開發與測試

原生 JavaScript ES modules + Canvas，無建置步驟、無外部套件。Node.js 24 已驗證。

```sh
node --test test/*.test.mjs
```

- `src/main.mjs`：串接遊戲與介面
- `src/rules.mjs`、`src/quest.mjs`：移動／潛行／任務規則
- `src/input.mjs`、`src/touch.mjs`：鍵盤與手機搖桿
- `src/render.mjs`、`src/minimap.mjs`：場景與局部地圖
- `src/save.mjs`：本機存檔驗證
- `assets/`：遊戲必要圖像；生成來源說明見 prompts JSON

## 限制

只有一條動物委託及三個小惡作劇；NPC 為靜態素材，沒有配音、帳號、雲端同步或多人模式。手機已用瀏覽器雙指事件驗證，尚未做實體手機長時間測試。存檔保存在瀏覽器，清除網站資料會失去進度。

這是私有原型儲存庫，尚無正式網站或部署流程。`nccu100` 僅作為校舍／地圖參考，沒有修改該專案。美術與角色使用模型生成素材，未搬用參考遊戲資產。
